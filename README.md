# meiji-orthography

AI のエージエント（Claude Code・Codex 等）に、日本語の囘答を明治後期（1900 年前後）の新聞の表記で書かせる爲のプロンプトである。

## 例

> 唐話が大切なのは、日常の言葉を覺えて互の氣持を通はせる爲だけではない。書物を讀み、文章を作るのにも、固より大きな關係がある。恰も膏には薤、雉には薌が缺かせないのと同じである。若し唐話に通じて居なければ、如何程廣く書物を漁り、多くの事を見聞きし、章句を彫り飾つて精緻を極めても、其の文は凸凹して滑でなく、口に支へ、齒に當り、ぎしぎしと軋んで句にならない。

## 何をするか

日本語のメツセージに答へる時だけ、チヤツトでの囘答を次の表記で書かせる。

- 舊字體（體・樣・從 等）
- 歴史的假名遣ひ（言ふ・だらう・書かう）
- 機能語の漢字表記（此の・其の・併し・既に・て居る 等）
- 明治 40 年の『送假名法』に依る送り假名
- 明治 39 年の『句讀法案』に依る句讀點
- 拗音・促音・外來語の音の大書き（しやう・行つた・フイルム）

文體（です・ます調か、である調か 等）は指定しない。新聞は表記の根據とし、話し方の根據にはしない。

## 使ひ方

使ふエージエント（Claude Code・Codex 等）に、次の一文を貼る。

```
https://github.com/rexao/meiji-orthography/blob/main/INSTALL.md を読んで、インストールして
```

エージエントが [`INSTALL.md`](INSTALL.md) の手順に從ひ、規則の本體の [`STYLE.md`](STYLE.md) を、自分の指示ファイルから讀み込む樣に設定する。

Web 版の Claude の樣に、エージエントが自分の設定を書き換へられない所では、[`STYLE.md`](STYLE.md) の中身を、設定（個人設定やプロジエクトの指示）に貼る。

1. 新聞: 當時の新聞の調査
2. 代用: 1 が見附からない場合の、同時代の標準・調査
3. 補助: 後の時代の資料
