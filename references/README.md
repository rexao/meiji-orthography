# 参考文献

`STYLE.md` の規則の根拠資料。

- 資料のファイルはリポジトリに含めない（著作権と容量のため）。下の「入手」に従って、このフォルダに「ファイル名」の名前で置く
- 普段の利用には不要。規則の出典を確かめたいとき、表に無い語の判断に迷ったときだけ読む
- 根拠は次の優先順位で選ぶ（`STYLE.md` の「根拠」の節と同じ）
  1. 新聞: 当時の新聞の調査
  2. 代用: 1 が見つからない場合の、同時代の標準・調査
  3. 補助: 後の時代の資料
- 書名は原本の表記（旧字体・歴史的仮名遣い）で書く

## NDL の OCR テキストの作り方（#2・#3・#4・#6）

国立国会図書館（NDL）デジタルコレクションの OCR 全文を、ページごとに書き出す。

```sh
curl -s https://lab.ndl.go.jp/dl/api/book/fulltext-json/<PID> \
  | python3 -c 'import json, sys
for p in json.load(sys.stdin)["list"]:
    print("=== page", p["page"])
    print(p["contents"])' > <ファイル名>
```

- `=== page N` の N は、NDL のビューアのコマ番号と同じ
- OCR なので誤りがある。怪しい箇所は、NDL のビューアで原本の画像を確かめる
- 縦組みの表や割注は、読む順が崩れやすい

## 1. 原科有里「新聞における漢字表記の減少過程」

- 書誌ページ: https://koara.lib.keio.ac.jp/xoonips/modules/xoonips/detail.php?koara_id=AN00072643-01230001-0143
- PDF: https://koara.lib.keio.ac.jp/xoonips/modules/xoonips/download.php/AN00072643-01230001-0143.pdf?file_id=170500
- 権利: 著作権は著者等にある。再配布しない
- ファイル名: `harashina2022_shinbun-kanji.txt`
- 作り方: PDF（テキスト層あり）を `pdftotext`（Poppler）で抽出。OCR ではないので本文は正確。グラフの数値は崩れる
- 注意: PDF の表紙に印字された書誌ページの URL は、ハイフンが抜けていて開けない。上の URL が正しい
- 使う箇所:
  - 「３．調査の概要」の調査対象語 73 項目とその漢字表記（機能語の表の出典）
  - 「４．調査結果」の時期別の傾向（1900 年は接続詞・副詞・指示詞等が 9 割以上漢字、助詞は仮名が半数以上）
  - 語ごとの割合があるのは表 1 の 8 語（マタ・オヨビ・ナオ・サラニ・シカシ・スデニ・スナワチ・マズ）だけ

- OCR: https://lab.ndl.go.jp/dl/api/book/fulltext-json/992577

  - `okurigana-ho_1907_scan.pdf`（原本の PDF。ビューアからダウンロード。画像のみ。ページ番号は txt の page と同じ）
