# 参考文献

`STYLE.md` の規則の根拠資料。

- 資料のファイルはリポジトリに含めない（著作権と容量のため）。下の「入手」に従って、このフォルダに「ファイル名」の名前で置く
- 普段の利用には不要。規則の出典を確かめたいとき、表に無い語の判断に迷ったときだけ読む
- 根拠は次の優先順位で選ぶ。根拠の無い規則は削る
  1. 新聞: 当時の新聞の調査
  2. 代用: 1 が見つからない場合の、同時代の標準・調査
  3. 補助: 後の時代の資料
- 根拠を要しない、このプロンプトの運用上の決め事は「設計」と呼ぶ
- `STYLE.md` には、出力に効く規則だけを書く。根拠の種類と出典は、下の「規則と根拠の対応表」に書く
- 書名は原本の表記（旧字体・歴史的仮名遣い）で書く

## NDL の OCR テキストの作り方（#2・#3・#4・#6）

国立国会図書館（NDL）デジタルコレクションの OCR 全文を、ページごとに書き出す。

```sh
curl -s https://lab.ndl.go.jp/dl/api/book/fulltext-json/<PID> \
  | python3 -c 'import json, sys
for p in json.load(sys.stdin)["list"]:
    print("=== page", p["page"])
    print(p["contents"])' > <ファイル名>
```

- `=== page N` の N は、NDL のビューアのコマ番号と同じ
- OCR なので誤りがある。怪しい箇所は、NDL のビューアで原本の画像を確かめる
- 縦組みの表や割注は、読む順が崩れやすい

## 7. 井口佳重「明治・大正期における新聞の仮名遣い改革」

- 書誌: 井口佳重「明治・大正期における新聞の仮名遣い改革」『日本語の研究』5 巻 2 号（2009）pp.16-30
- PDF: https://www.jstage.jst.go.jp/article/nihongonokenkyu/5/2/5_KJ00005690923/_pdf （J-STAGE。テキスト層あり）
- 権利: 著作権は著者等にある。再配布しない
- ファイル名: `iguchi2009_shinbun-kanazukai.pdf`
- 使う箇所:
  - p.18 本文と表Ⅰ: 明治 20〜30 年代の新聞は、ほぼ総ルビで、振り仮名は歴史的仮名遣いで書かれていた。1900 年 4 月時点で、大阪毎日新聞・毎日新聞を除く主要新聞（東京日日・時事・報知・読売・東京朝日・大阪朝日 等）の字音仮名遣いは歴史的仮名遣い
  - p.20 表Ⅱ: 新聞の振り仮名の拗音は大書き（きやう・しやう 等）。同じ表で、第一期国定教科書（1903〜）は小書き（きょー・しょー 等）
  - p.27 注 8: 学校教育の「新定字音仮名遣」（1900）では、拗音の「や」「ゆ」「よ」は小書き
- 注意: 調べているのは、主に字音語の振り仮名。大阪毎日新聞は 1900 年 4 月 21 日から、字音を表音的に書く独自の仮名遣いを使った
